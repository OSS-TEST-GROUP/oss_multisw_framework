vECU 를 개발하기 위한 SiLS 환경

개발자는 MMF SDK(libsils_vecu)로 vECU 하나를 만들고(왼쪽), 그것을 MORAI/rosbag(세계) · Autoware(두뇌) · VISS 허브 · 다른 ECU와 같은 DDS 버스에 올려 실행·검증한다(오른쪽). 컨테이너 기동은 lifecycle_mgr+adsw_manager, 판정은 conformance gate. 같은 이미지가 그대로 실보드로 간다(shift-left).

경계 & 구현 상태 — "어디까지 SiLS"

SiLS는 링 1만 소유한다. 링 2는 계약(DDS/VSS·trace)으로 붙는 외부, 링 3은 범위 밖. 아래는 각 요소가 이미 구현됨(teal)인지 설계만(amber)인지 표시 — MORAI 빼고 대부분 이미 구현돼 있다.

구현됨 설계만 (MORAI) 범위 밖 (외부/HW) ★ 개발 대상

컨테이너 컴포넌트 구성 (배포 관점)

각 요소는 컨테이너 하나다. SDK로 빌드한 vECU 는 멀티 인스턴스(각자 컨테이너), MMF 오케스트레이션·VISS 허브도 컨테이너. 바깥에 MORAI/rosbag · Autoware · AGL 연동 컨테이너. 전부 아래 DDS pipeline에 물린다(같은 도메인).
