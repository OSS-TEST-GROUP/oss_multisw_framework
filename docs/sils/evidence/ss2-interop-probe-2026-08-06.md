## Domain sharing

ROS 2 nodes seen: `scenario_node`, `simple_sensor_simulator`, `visualizer`

> ⚠ **This DDS domain is shared with non-ROS participants.** The endpoints below report `_CREATED_BY_BARE_DDS_APP_`, meaning a pure DDS application (not the simulator) is on the same domain.

> Two consequences, opposite in sign:

> - **Good:** bare-DDS ↔ ROS 2 discovery demonstrably works here — the central BR-C-2a question, answered affirmatively for this RMW.
> - **Bad:** a SiLS golden/regression run on a shared domain can match foreign endpoints. Give loop B its own domain id before capturing goldens.
