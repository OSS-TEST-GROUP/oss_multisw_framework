05

실증: Feedthrough 궤적

Reference-FMU Feedthrough(FMI 3.0)는 출력=입력 통과 → uₙ = 0.8·(10 − uₙ₋₁). 감쇠 진동하며 4.44로 수렴. 두 번 독립 실행이 소수점까지 동일.

07

도입 주의

ARM64 바이너리

fmi4c가 ARM64로 빌드돼도 FMU 안에 aarch64-linux/*.so가 없으면 실행 불가. 대상 아키텍처 바이너리(또는 소스)를 계약으로 요구.

변수 매핑

현재 raw valueReference(SILS_FMU_INPUT_VR/OUTPUT_VR)로 지정, Float64만. 향후 Contract↔FMU 이름·단위·causality 매핑으로 확장.

시간 소유권

FMU가 임의 wall-clock을 쓰면 안 됨. doStep(time_, dt)로 lockstep dt 누적 → sim_time == FMU time. 결정론의 전제.

실패 정책 (fail-fast)

load 실패 · 버전 불일치 · init 실패 → probe 종료. doStep 오류 · NaN/Inf → 출력 NaN → §14 fail-fast.

MORAI와 상태 소유권

FMU와 MORAI가 동시에 같은 차량 동역학을 계산 금지. MORAI가 authority면 FMU는 미사용 또는 보조 모델(타이어·브레이크)로 제한.

보안 — FMU=native code

.fmu 안 .so는 실제 native. 신뢰 안 되는 FMU = 임의 코드 실행. 격리 컨테이너 · hash/공급자 기록 · allowlist.
